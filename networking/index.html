★ Network Programming

Welcome to my networking notes! I'm teaching myself how programs talk to each other over a network — from raw sockets all the way up the stack. Think of this as my public learning journal: every entry is what I studied that day, written in my own words.

The plan is simple. Read, code, break stuff, write it down. Most of what you'll see here follows Beej's Guide to Network Programming, with my own notes and the C code I compile along the way.

⚑ Cheat Sheet

Handy calls so far

  • socket() — create a socket, get its file descriptor
  • bind() — attach the socket to a port on a local address
  • send() / recv() — push and pull data

Two socket families to remember

  • SOCK_STREAM — reliable, ordered, connection-based (TCP)
  • SOCK_DGRAM — connectionless, may drop or reorder (UDP)
